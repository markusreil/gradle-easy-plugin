# AGENTS.md

## Project Overview
Gradle plugin project (`gradle-easy-plugin-new`) — skeleton generated by `gradle init`. Kotlin + `java-gradle-plugin`, single subproject `plugin/` publishing plugin `org.example.greeting` (`org.example.GradleEasyPluginNewPlugin`).

## Structure
```
settings.gradle.kts          # includes :plugin
gradle.properties            # configuration-cache, parallel, caching enabled
gradle/libs.versions.toml    # version catalog (kotlin-jvm 2.3.0)
plugin/build.gradle.kts      # plugin build, test suites, gradlePlugin block
plugin/src/main/kotlin/      # plugin implementation
plugin/src/test/kotlin/      # unit tests (kotlin.test)
plugin/src/functionalTest/kotlin/ # functional tests via Gradle TestKit (GradleRunner)
```

## Commands
```bash
./gradlew :plugin:check              # all checks (unit + functional tests)
./gradlew :plugin:test               # unit tests only
./gradlew :plugin:functionalTest     # functional tests only
./gradlew :plugin:build              # build + checks
./gradlew :plugin:publishToMavenLocal # publish for local consumption
./gradlew build                      # root build (delegates to :plugin)
```

Use `./gradlew` (wrapper, Gradle 9.4.1) — do not use a system `gradle`.

## Conventions
- Kotlin DSL (`build.gradle.kts`, `settings.gradle.kts`).
- Plugin registration in `plugin/build.gradle.kts` via `gradlePlugin { plugins.creating { id, implementationClass } }`.
- Functional test source set (`functionalTest`) wired via `gradlePlugin.testSourceSets.add(...)` and `check.dependsOn(functionalTest)` — keep this wiring.
- Configuration cache / parallel / build cache are on — new tasks must be CC-compatible (no `project` at execution time, use providers/properties).
- Keep `plugin/src/main|test|functionalTest` layout.

## Testing
- Unit tests: `src/test` with `kotlin.test` (`useKotlinTest("2.3.0")`), mock `Project` with `ProjectBuilder`.
- Functional tests: `src/functionalTest` uses `GradleRunner` / `gradleTestKit()` against a temp project — require `implementation(project())` dependency.
- Run `./gradlew :plugin:check` before submitting.

## Dependencies
- All dependencies and plugins must be declared in `gradle/libs.versions.toml` (version catalog) and referenced by alias (e.g., `alias(libs.plugins.kotlin.jvm)`, `libs.junit.jupiter`). Do not hardcode coordinates or versions in `build.gradle.kts`.

## Editing Guidelines
- Prefer editing over creating files. Match existing Kotlin style (no extra comments unless requested).
- When adding a new plugin/task/extension, update `gradlePlugin` block, add tests in both suites, and verify with `check`.
- Do not disable configuration cache, parallel, or caching without justification.
